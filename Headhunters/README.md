# DreamQuest

A fantasy card game designed by Patrick Wadsack-Stewart.

[Browse the card collection](https://paddyws.github.io/Clovers-Great-Escape/Headhunters/)

The gallery contains 311 card designs: 69 heroes, 132 items, and 110 spells. It presents the supplied card artwork and rules text as a browsable design portfolio, with category filters, full-size viewing, keyboard navigation, and individual card downloads.

Card images are web-optimized AVIF copies at the original 750 × 1050 pixel dimensions. Category data packs contain up to 24 images each and load as their cards approach the viewport. The three featured cards use self-contained SVG image files. Individual cards can be downloaded from the gallery. The duplicated hero archive was omitted.

## Local preview

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000/Headhunters/`.

The gallery uses plain HTML, CSS, and JavaScript; no build step or third-party scripts are required.
