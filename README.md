# Clover's Great Escape and Headhunters

Game projects by Patrick Wadsack-Stewart.

- [Play Clover's Great Escape](https://paddyws.github.io/Clovers-Great-Escape/): a browser game built with HTML, CSS, and JavaScript.
- [Explore Headhunters](https://paddyws.github.io/Clovers-Great-Escape/Headhunters/): a gallery of 311 hero, item, and spell card designs from Patrick's fantasy card game.

Clover's Great Escape lives at the repository root. The Headhunters gallery lives in `Headhunters/` and is published through the existing GitHub Pages site.
